# Clean Package Notes

This clean handoff removes qpdf and veraPDF binaries/installers. It keeps the folder structure simple and preserves each source example/reference package as a whole file.

Parts:

- Part 01: core docs/rules/scripts/skill/prompt/templates/checklists/manifests.
- Part 02: examples/source_examples and examples/qa_crops.
- Part 03A: reference output packages, set A.
- Part 03B: reference output packages, set B.

No PDF or reference output package is split across multiple parts.
